# TOK — полноценное Android-приложение

Эта сборка переносит исходный интерфейс и игровую/учётную логику TOK в устанавливаемое Android-приложение. Исходные React-компоненты и стили сохраняются, а приложение открывает их из локальных ресурсов внутри APK.

## Что включено

- **Смена:** старт/завершение текущей смены, фиксация дохода, часов и заказов, создание/редактирование/удаление записей.
- **Цели:** дневные и недельные показатели, прогресс и серии.
- **Путь:** опыт, уровни, ранги, квесты, награды и достижения.
- **Магазин оформления:** темы, цветовые акценты, транспорт и титулы.
- **Разбор:** статистика за периоды, графики дохода/заказов, календарь и аналитика.
- **Профиль:** имя, настройки, история смен и управление данными.

Данные сохраняются локально на устройстве через хранилище приложения. В исходном проекте нет серверной синхронизации, поэтому эта сборка не синхронизируется с браузерной версией. После первой установки приложение может работать без интернета.

В этой версии **нет Android-виджета** — только полное приложение.
