# TOK Widget for Android

Нативный Android App Widget для TOK: доход за день, доход в час, количество заказов, отработанные часы и прогресс дневной цели.

## Возможности

- Виджет на домашнем экране Android.
- Быстрые кнопки: начать/завершить смену, +1 заказ, +100 ₽.
- Автоматический сброс дневных показателей при смене календарной даты.
- Экран ручной корректировки заработка, заказов, часов и цели.
- Импорт JSON-состояния Zustand из `localStorage` ключа `tok-courier`.

## Синхронизация

Android App Widget не имеет прямого доступа к `localStorage` Chrome/PWA. Поэтому импорт делается явным JSON-экспортом состояния TOK. После импорта быстрые изменения виджета хранятся отдельно в приложении-компаньоне.

## Сборка APK

Workflow `.github/workflows/build-apk.yml` соберёт APK в GitHub Actions. Выходной файл: `app/build/outputs/apk/debug/app-debug.apk`.
