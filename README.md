# TOK Widget for Android

Нативный Android App Widget для быстрого учёта курьерской смены.

## Что умеет виджет

- Показывает заработок за смену, количество заказов, отработанное время и расчётный доход в час.
- Кнопка начала/завершения смены управляет таймером.
- Кнопка «+ заказ» добавляет заказ и условные 100 ₽.
- Кнопка «+100 ₽» добавляет доход без изменения числа заказов.
- Экран приложения позволяет обновить виджет или сбросить показатели.

## Установка виджета

После установки APK откройте приложение один раз. Затем на главном экране Android зажмите пустое место → «Виджеты» → «TOK Widget» и добавьте виджет.

## Сборка

GitHub Actions автоматически собирает debug APK при push в `main` или вручную через вкладку Actions. Готовый файл публикуется как артефакт `TOK-Widget-debug-apk`.

## Важно

Данные этой первой Android-версии хранятся локально на устройстве. Автоматической синхронизации с веб-приложением TOK и импорта из браузерного localStorage пока нет. Для реальной синхронизации потребуется отдельный API/экспортный мост.
